## 1. Как работает услуга Puma Delivery (со слов владельца и с главной)

- Передачи Россия ⇄ Таиланд — **через пилотов и стюардесс** на прямых и
  стыковочных рейсах, в обе стороны. Владелец 2026-09-28: «мы возим пилотами
  туда-сюда».
- Пример с главной: посылка может вылететь из Москвы вечером и быть в Бангкоке
  утром следующего дня. Рейс подбирают под нужный срок.
- Чаще всего из России везут лекарства, документы для виз, посылки для
  родственников; обратно — тайскую косметику, фрукты, сувениры, образцы для
  бизнес-партнёров (формулировка главной).
- По Таиланду: курьеры в Бангкоке, Паттайе, Пхукете, на Самуи и Пангане;
  доставка в тот же день при заявке до 20:00; поручения (купить по списку,
  забрать заказ, передать документы); выкуп с Lazada/Shopee, покупки в Boots,
  Watsons, Central, Big C, Makro.
- Поиск тайских поставщиков и оптовая отправка в Россию через логистов (не
  пилотами).
- Не возят: электронные сигареты и вейпы, оружие, наркотики, виды под CITES,
  крупногабарит.
- Стоимость индивидуальна (город, вес, срочность, рейс). **Цен не называть.**
- Контакт для заявки: Telegram `https://t.me/kolesnikov1988`; ВКонтакте
  `https://vk.com/pumainthailand`. Автор статей — Дмитрий Колесников,
  основатель (`https://pumadelivery.ru/about.html#dmitry`).

**Честная рамка услуги (обязательна в текстах).** Передача через экипаж — это
небольшие посылки для личного пользования. Экипаж вправе отказаться от вложения;
вложение проверяется при приёме; запрещённое и контролируемое не берём.
Коммерческие партии — только через карго/логистов, не пилотами.

## 3. Правила — въезд в Таиланд (для M1)

- **Лекарства (Thai FDA).** Обычные препараты для личного применения можно
  ввозить в количестве **не больше чем на 30 дней**. Препараты с наркотическими
  и психотропными веществами (Schedule II/III; кодеин есть в тайском списке
  контролируемых) требуют **предварительного разрешения Thai FDA**, а
  послабление для пациента **не распространяется на почтовые отправления**.
  Источники: en.fda.moph.go.th (гид по ввозу для личного пользования; гид для
  путешественников с наркосодержащими лекарствами). Популярный пример риска —
  пенталгин и другие кодеинсодержащие (Вордстат: «пенталгин можно ли ввозить в
  тайланд»). Вывод для статьи: такие препараты пилотом не передаём.
- **Еда (Thai FDA).** Общий предел ввоза еды для личного пользования —
  **10 кг (или 10 л)**; продукты животного происхождения регулируются отдельно
  (мясные продукты — зона ветеринарного контроля, возможны изъятие и
  требования разрешений). **Предположение, не проверено:** точные условия для
  сала и колбасы — писать «мясные продукты — только заводская упаковка и после
  согласования с нами; риск изъятия на границе», без цифр.
- **Запрещено в Таиланд:** электронные сигареты и вейпы, наркотики. Алкоголь
  и сигареты — нормы (1 л, 200 сигарет) уже описаны в
  `/blog/chto-nelzya-vvozit-v-tailand.html`; ссылаться туда.
- **Личные вещи (Thai Customs).** Personal effects — одежда и книги в
  разумном количестве; household effects при переезде — отдельные условия.
  Много одинаковых новых вещей выглядит как товарная партия (thai-rus.ru,
  2026-08-11).
- Книги, документы — ограничений по ввозу нет (документы экипаж передаёт в
  конверте; оригинал паспорта — только по согласованию, риски потери несёт
  отправитель — **формулировка постановщика, не факт закона**).

## 4. Правила — въезд в Россию (для M2)

- **Товары для личного пользования в сопровождаемом багаже при прилёте
  самолётом:** без пошлины — стоимостью **до 10 000 евро и весом до 50 кг**
  (ФТС; t-j.ru 2026-01-18; сайт МИД). Разумное количество — одинаковые новые
  вещи (несколько одинаковых телефонов) таможня может признать не личными.
- **Интернет-покупки посылками** (не наш канал, упоминать для сравнения): с
  2026 года порог беспошлинного ввоза — **200 евро** (решение Совета ЕЭК,
  Ведомости 2026-01-12); сверх — 15% от превышения, не менее 2 евро/кг
  (**предположение по сумме за кг — не писать цифру за кг**). Обсуждается НДС
  22% на трансграничные покупки (Интерфакс, сентябрь 2026) — упоминать как
  «обсуждается», без дат вступления.
- **Лекарства (ФТС, customs.gov.ru/fiz/pravila-peremeshheniya-tovarov/lekarstvennye-sredstva):**
  для личного использования — можно; препараты с наркотическими,
  психотропными, сильнодействующими веществами — только с медицинскими
  документами (рецепт/выписка) и **обязательным декларированием**. Вывод для
  статьи: такие препараты экипажем не передаём; безрецептурные — в заводской
  упаковке, в количестве для личного применения.
- **Растительная продукция (фрукты):** пассажир может ввезти **до 5 кг**
  подкарантинной продукции без фитосанитарного сертификата (Решение Совета
  ЕЭК № 157 от 30.11.2016) — правило для багажа, не для посылок.
  Дуриан многие авиакомпании не принимают к перевозке из-за запаха
  (**формулировка «многие авиакомпании» — без названий**).
- **Животная продукция:** до 5 кг готовой продукции в заводской упаковке
  (ФТС) — для багажа.
- **Литиевые батареи:** в авиапочте запрещены (Почта России); пассажиру
  запасные батареи и пауэрбанки — только в ручной клади (IATA). Электроника с
  встроенной батареей — по правилам авиакомпании.
- **Почта России не пересылает:** наркотические/психотропные вещества, в том
  числе в лекарствах; скоропортящиеся продукты; растения
  (info.pochta.ru/support/post-rules/prohibited-for-delivery).
- **Электроника в Таиланде:** iPhone продаются официально (Apple Store в
  Бангкоке — **предположение, не проверено: не писать адреса/цены**).
  Тайская версия — обычная международная; цены не называть.
